# treg

A Node/TypeScript wrapper around `ffmpeg` with a customizable progress display and readable error messages.

> **Status:** early development. See [docs/PLAN.md](docs/PLAN.md).

## Standing on ffpb's shoulders

treg is a port of [ffpb](https://github.com/althonos/ffpb) by Martin Larralde (MIT).
Full credits and a comparison with ffpb will be added here.
